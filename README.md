# HEAT

시계열적 요소를 종합하여 서울 시내의 핫플레이스를 정의하고 떠오르는 지역을 예측하는 시스템

한양대학교 시계열데이터분석및실습 Team #14. 서울 427개 행정동을 단위로 **지금의 핫스팟**과 **떠오르는 곳**을 찾는다.

```
          입력 (예측 시점에 아는 값만)                   정답 (2023-01 ~, 주 단위)
  ┌──────────────────────────────────┐        ┌──────────────────────────────────┐
  │ 과거 생활이동 (주)                │        │ 생활이동 도착량                   │
  │ 네이버 검색 (월, 서울 대비 비중)  │ ─────▶ │ 20~39세, 목적 4+5+7, 주 일평균    │
  │ 음식점 영업 점포 변화 (주)        │ 13주 앞 │  · 현재 핫스팟: 수준              │
  │ 지하철 하차 (주), 달력·명절       │  예측   │  · 떠오르는 곳: 1년 전 대비 성장  │
  │ 생활인구 (주, 따로 시험)          │        └──────────────────────────────────┘
  └──────────────────────────────────┘
                     결과는 행정동 지도(maps/)로 본다
```

**제안서 피드백에 대한 우리의 답**: 여러 지표를 가중합한 Hotness Score를 만들지 않는다. 대신 **관측된 생활이동(비정기 목적 도착)을 정답으로** 쓴다. 그래서 가중치를 임의로 고를 일이 없고, 정답이 예측 입력으로 만들어지지도 않는다.

## 1. 지금까지 한 것

### 1.1 행정동 이름표

사람들이 어떤 이름으로 그 동을 검색하는지 정했다. 동마다 세 종류의 이름을 붙이고 가중치를 줬다.

| 칸 | 기준 | 예 |
|---|---|---|
| 동네 | 법정동 면적이 행정동 육지 면적의 10% 이상 | 성수동, 연남동 |
| 역 | 같은 강변 1,000m 원 안 육지 면적이 5% 이상 | 성수역, 뚝섬역 |
| 상권 | 상권 영역 면적의 10% 이상이 동 안 | 서울숲 카페거리 |

- 결과: 427동, 이름 묶음 566개. `data/processed/nametags/01~07`
- 자세한 규칙: `reports/nametags/00_결과_요약.md`

### 1.2 네이버 검색량

- **수집**: NAVER API HUB 검색어 트렌드로 566묶음 × 방문 의도어 6개(맛집, 카페, 술집, 데이트, 가볼만한곳, 핫플)를 모았다. 기간은 2022-01~2026-10, 월 단위다.
- **척도**: 모든 요청에 같은 기준 묶음(문래)을 넣어 척도를 맞췄다. 조회 기간을 늘려도 과거 값이 바뀌지 않는다.
- **동별 지수**: 서울 전체 검색량이 2022→2025년 14% 줄어서, 동 비교는 **서울 대비 비중**으로 한다.
  - 변화는 네 가지로 본다: 지난달, 3개월, 3개월 계절 보정, 1년.
  - 검색량이 너무 적거나 다른 뜻과 겹치는 묶음 160개를 뺐다(예: 방학, 양평).
- **결과**: 지수가 있는 동 422개. `data/processed/search/행정동_검색지수_월별.csv`
- 자세한 내용: `reports/search/00_검색량_요약.md`

### 1.3 음식점 개폐업

- **자료**: 서울시 인허가 일반·휴게음식점에서 편의점·구내매장 등을 뺐다. 점포 좌표로 2025-12-31 경계 행정동에 붙였다(93.7%).
- **동×월 표**: `data/processed/fnb/행정동_개폐업_월별.csv` (2022-01~2026-09, 서울·구·동)

  | 열 | 뜻 |
  |---|---|
  | `개업` | 그 달 개업 수 |
  | `폐업_일괄제외` | 그 달 폐업 수. 같은 날 한꺼번에 처리된 행정 정리(일괄 폐업)는 뺌. **기본값** |
  | `폐업_일괄포함` | 일괄 폐업을 포함한 폐업 수 |
  | `영업점포` | 그 달 말 영업 중인 점포 수 |
  | `영업점포_<업종>` | 업종 12개별 영업 점포 |

- **점검 결과**:
  - 일괄 폐업이 2024년부터 두 배가 됐다(전체 폐업의 4% → 9~10%).
  - 폐업 기록의 99%가 폐업일 30일 안에 반영된다.
  - 장충동·묵2동·공릉2동·가락1동은 행정 재등록으로 보여 순위에서 뺀다.
  - 2026-10은 일부만 집계돼 쓰지 않는다.

### 1.5 검색량·개폐업 예측 실험

검색량과 개폐업 자체를 2022~2025년으로 학습해 3개월 앞을 예측해 봤다. 정답 모델에 넣기 전에 두 자료의 성질을 알기 위한 실험이다.

- 계획: `docs/forecast_plan.md` · 코드: `src/forecast/` · 리포트: `reports/forecast/00_결과_리포트.md`
- 검증: 학습 2022~2023 → 시험 2024, 학습 2022~2024 → 시험 2025
- 모델: Naive, 계절 Naive, ETS, Theta, SARIMA, Croston/TSB, SARIMAX, LightGBM, Ridge

| 확인한 것 | 수치 | 뜻 |
|---|---|---|
| 개폐업은 기준선을 넘는다 | 동별 개업·폐업·순증률 MASE 0.92~0.99 (계절 naive 1.12~1.26), 두 해 모두 유의 | 단순한 ETS·Ridge로 충분 |
| 검색은 2024년만 맞혔다 | 2024 MASE 0.97(유의), 2025 2.25(계절 naive 2.20과 차이 없음) | 해마다 결론이 달라질 수 있다 |
| 3개월을 넘으면 예측력이 사라진다 | 12개월 앞 개업 수는 Naive와 같다 | 예측 거리는 짧게 |
| 검색과 개폐업은 서로 돕지 않는다 | 서로 넣어도 같거나 조금 나빠짐 | 3개월 안에서는 별개 신호 |
| 큰 곳은 계속 크고, 크는 곳은 바뀐다 | 동 순위상관: 검색 비중 0.99, 개업 수 0.91~0.93, 순증률 0.11~0.19 | "떠오르는 곳"은 따로 평가해야 한다 |
| 서울 음식점은 2024년부터 줄고 있다 | 영업 점포 2023년 말 최고 → 2년간 −3.9% | 2025년이 더 어렵다 |

**현재 핫스팟과 떠오르는 곳** (기술 통계, 2026년 가을 기준)

| | 현재 핫스팟 | 떠오르는 곳 |
|---|---|---|
| 검색 | 성수, 용산(한강로·용산2가·이촌2), 잠실 | 광진구 군자역~아차산 일대(군자·능동·중곡1·2) |

## 2. 정답과 핫스팟 정의

### 2.1 정답: 생활이동 비정기 목적 도착량

**정의**: 20~39세, 목적 4(쇼핑)+5(관광)+7(기타), 도착 행정동 기준, **주 단위 일평균**.
통근·통학·귀가·병원(1·2·3·6)은 뺀다. 출처는 [서울시 수도권 생활이동](https://data.seoul.go.kr/dataList/OA-22298/F/1/datasetView.do)이고, 2023-01부터 있다.

| 후보 | 장점 | 정답으로 쓰기 어려운 점 | 역할 |
|---|---|---|---|
| **생활이동 4+5+7** | 실제로 "놀러 온" 양에 가장 가까움. 동·일 단위 | 통계적 추정치. 품질 이슈(2024-08~10 급증, 2025-09~ 원천 변경). "기타"가 넓음 | **정답** |
| 네이버 검색량 | 관심이 먼저 보임 | 방문이 아닌 관심, 전국 검색, 상대 지수. 우리가 만든 지표라 정답이면 자기 입력을 맞히는 셈 | 입력 |
| 음식점 개폐업 | 공급 변화 | 수요를 늦게 따라옴, 동 단위 잡음 큼 | 입력 |
| 지하철·버스 하차 | 실측 | 역·정류장 단위, 출퇴근 섞임 | 입력 (버스는 다음 단계) |
| 생활인구 | 실측에 가까움 | 정답과 같은 통신 기반이라 겹침. 2026-07 생산 종료 | 따로 시험 |
| 상권 매출 | 돈의 흐름 | 분기, 공개 늦음 | **검증 전용** |

### 2.2 핫스팟 정의

| 구분 | 정의 | 뜻 |
|---|---|---|
| **현재 핫스팟** | 최근 13주 평균 정답 **상위 10%** 동 | 지금 사람이 많이 오는 곳 |
| **떠오르는 곳** | 최근 13주 평균의 **1년 전 같은 13주 대비 증가율 상위 10%** 동. 증가율은 서울 대비 비중으로 계산하고, 규모가 작은 동은 제외 (하한 = 2023년 동별 평균의 하위 25% 경계로 고정, 하루 약 2,050명) | 1년 전보다 가장 많이 늘어난 곳 |
| **예측에서** | 같은 규칙을 다음 13주 예측값에 적용. 1년 전 같은 13주는 이미 관측된 값 | 앞으로 13주의 핫스팟·떠오르는 곳 |

**이렇게 정한 이유**
- **상위 10%로 통일**: 두 정의가 같은 규칙이라 일관된다. "+20%" 같은 고정 숫자가 없어 서울 전체가 오르내려도 기준이 같이 움직인다.
- **1년 전 같은 13주와 비교**: 계절이 저절로 빠진다. 13주는 예측 거리와 같다.
- **13주 평균**: 한 주짜리 행사 급등이 묽어져 별도 지속 조건 없이도 일시적 급등이 걸러진다.
- **규모 하한**: 작은 동은 조금만 늘어도 증가율이 크게 튄다(검색·개폐업 분석에서 확인). 하한은 2023년 값으로 한 번 정해 고정한다. 시점마다 다시 계산하는 방식과 목록 겹침 93%.
- **서울 대비 비중**: 현재 핫스팟은 같은 주 안의 순위라 원값과 결과가 같다. 떠오르는 곳에서는 서울 전체가 같이 움직인 부분(자료 원천 변경, 전체 감소)을 뺀다.
- **민감도**: 상위 5·10·20%, 제외 규모 하위 0·25%, 목적 4+5 vs 4+5+7, 연령 20~39 vs 전체로 바꿔 목록이 얼마나 겹치는지 보고한다.

**참고한 선행연구** (정의를 더 엄격하게 할 때)
- 시공간 핫스팟 분류: [ArcGIS Emerging Hot Spot Analysis](https://desktop.arcgis.com/en/arcmap/latest/tools/space-time-pattern-mining-toolbox/learnmoreemerging.htm) (Getis-Ord Gi\* + Mann-Kendall, 새로운·연속·강해지는 핫스팟)
- 자료에서 정하는 핫스팟 문턱값: [Louail et al. (2014)](https://arxiv.org/pdf/1401.4540) (휴대폰 데이터, LouBar)
- 새로 생기는 군집 탐지: [Kulldorff (2001)](https://econpapers.repec.org/RePEc:bla:jorssa:v:164:y:2001:i:1:p:61-72)
- 개업이 동네 변화보다 먼저 나타남: [Glaeser, Kim, Luca (2018)](https://www.nber.org/papers/w24952)
- 국내 공식 분류(외부 검증용): [서울시 상권변화지표](https://golmok.seoul.go.kr/policy/sectorAnalysis.do)

### 2.3 성공한 예측이란

1. **정확도**: 13주 예측 오차가 **작년 같은 주** 기준선보다 작다. 여러 예측 시점에서, DM 검정으로 확인한다.
2. **판정**: 예측으로 뽑은 떠오르는 곳이 실제 떠오르는 곳과 겹친다. 상위 K개(10·20·30) 적중률이 기준선과 무작위보다 높아야 한다.

**작년 같은 주 기준선은 떠오르는 곳 순위를 못 매긴다.** 다음 13주를 1년 전 같은 주 값으로 예측하므로, 모든 동의 예측 증가율이 0이 된다. 오차는 가장 작아도 변화에 대한 정보가 없다. 그래서 판정 평가의 비교 기준은 다음 둘이다.
- **무작위**: K ÷ 동 수
- **지속**: 직전 13주의 1년 전 대비 증가율이 다음 13주에도 그대로 이어진다고 보는 예측

### 2.4 정답 타당성 점검

정답은 **예측이 잘 되는 쪽으로 고르지 않는다.** 대신 아래 네 가지로 "핫플레이스를 제대로 가리키는가"를 본다.

1. **알려진 핫플**: 미리 정한 목록(성수·연남·용산·을지로·한남 등)이 상위에 드는가
2. **외부 근거**: 입력에 쓰지 않는 자료(상권 추정매출)와 같은 방향인가
3. **품질**: 급등·급락 주가 문제 구간에 몰려 있는가
4. **정의 민감도**: 목적·연령을 바꿔도 동 순위가 비슷한가

### 2.5 기존 서비스와의 차이

| 서비스 | 보여 주는 것 | HEAT |
|---|---|---|
| 지도 앱 핫플 | 가게 단위, 리뷰·광고 기반, 지금의 인기 | 동 단위 **실제 이동**, **13주 앞 예측** |
| 검색 트렌드 (데이터랩) | 키워드 관심 추이, 위치 정리 없음 | 검색을 동에 매핑해 **이동 예측 신호**로 사용 |
| 상권분석서비스 | 분기별 과거 매출·유동 | **주 단위로 앞을 봄**, 이미 큰 곳과 **떠오르는 곳을 구분** |

## 3. 무엇으로 무엇을 예측하고 무엇을 검증하나 (주 단위)

### 3.1 시간 단위와 예측 거리

- **주 단위, 13주(약 3개월) 앞**을 예측한다. 주는 월요일~일요일.
- 월 단위(28개 시점)보다 주 단위(약 120개 시점)가 학습 자료가 많다. 다만 정답이 2023-01부터라 **1년 계절은 여전히 2번 남짓만** 관측된다.

### 3.2 입력과 붙이는 규칙

**원칙**: 예측 시점 이후 값은 쓰지 않는다. 13주 앞까지 모든 입력값이 예측 시점에 이미 알려져 있어야 한다.

| 입력 | 단위 | 만드는 값 | 규칙 |
|---|---|---|---|
| 과거 정답 | 주 | 최근 값, 4주 평균, 작년 같은 주(364일 전) | 예측 시점까지 |
| 네이버 검색 | 월 | **서울 대비 비중**, 계절 보정 변화 | 예측 시점에 끝난 마지막 달 값을 13주 동안 고정, 또는 각 주에 4개월 전 달 값. 둘 중 하나로 정해 명시 |
| 음식점 | 월 → 주 | **영업 점포 12개월 변화율** (일괄 폐업 제외). 중간발표는 동×월 표 값을 검색처럼 붙이고, 최종 전에 개업·폐업 날짜로 주마다 계산 | 신고 지연 때문에 **5주 전 값**까지 사용 |
| 지하철 하차 | 주 | 동 연결 역의 **최근 4주 평균 하차** (이름표 `05` 가중치) | 예측 시점까지 |
| 생활인구 | 주 | 주간(11~21시) 평균 | 정답과 겹치는 자료라 **따로** 시험 |
| 달력 | 주 | 공휴일 수, **설·추석 더미** | 미래 날짜가 정해져 있어 시차 없이 사용 |

- 검색은 API가 주 단위도 지원한다. 주 단위로 다시 받아도 요청은 431회 남짓이라 월 한도(5만 회) 안이다. 다만 0인 주가 늘어 제외 규칙을 주 단위로 다시 정해야 한다. (다음 단계)
- 개업·폐업 **건수**는 동당 주 0.5건 수준이라 주 단위로는 잡음뿐이다. 그래서 점포 수 기반 값을 쓴다.
- **값을 고른 기준**: 빠르게 움직이는 자료(지하철, 생활인구, 검색)는 **최근 수준**, 느리게 움직이는 자료(음식점)는 **1년 변화**. 지하철 4주 평균은 명절·행사 한 주의 흔들림을 줄인다. 음식점 12개월 변화는 12월 폐업 몰림 같은 계절도 저절로 뺀다.
- **입력은 소스당 값 하나**로 시작한다. 동마다 주 약 110개로 SARIMAX를 적합하므로 입력이 많으면 과적합·수렴 실패가 난다.

### 3.2.1 지역 단위: 이름표 427동 (지도 클릭 단위)

모든 자료를 이름표를 만든 2025-12-31 경계 427동으로 맞춘다.

| 자료 | 427동으로 맞추는 법 |
|---|---|
| 네이버 검색, 음식점 | 이미 427동 (검색 지수가 있는 동 422) |
| 지하철 하차 | 이름표 `05` 역–동 연결 가중치로 나눔 |
| 버스 (다음 단계) | 정류장 좌표로 동에 붙임 |
| 생활이동, 생활인구 | 서울시 행정동 코드 → 427동 **코드 대응표**. 그 사이 나뉜 동(예: 2025년 용신동 분리)은 분석에서 다시 합쳐 하나로 보거나, 분리 전 기간을 `not_estimable`로 표시 |

비교할 때는 모든 입력이 있는 동으로 집합을 맞춘다 (예: 지하철은 역이 연결된 동만 값이 있음).

### 3.3 계절과 행사

**계절**: 2년 남짓으로 52주 계절을 직접 추정하기는 어렵다. 그래서 적은 모수로 넣는다.
- 작년 같은 주 값 (기준선이자 외생변수)
- 푸리에(사인·코사인) 계절 항 2~4쌍 (강의 W5)
- 서울·구 합계에서 계절 모양을 빌려 와 동에 적용

**행사 급등**

| 종류 | 예 | 처리 |
|---|---|---|
| 매년 반복 | 불꽃축제(10월 초), 벚꽃 | 계절로 본다. 작년 같은 주 값이 잡아 준다 |
| 날짜를 미리 아는 일회성 | 마라톤, 대형 콘서트 | 행사 더미 (다음 단계) |
| 미리 모르는 급등 | 갑작스러운 행사, 자료 오류 | 기준선 대비 MAD의 k배 이상이고 1~2주 안에 돌아오면 표시. 학습에서 윈저라이징, 평가는 넣고 뺀 결과 모두 (다음 단계) |

떠오르는 곳의 **지속 조건**(8주 이상)이 일회성 행사를 걸러 준다.

### 3.4 모델

| 단계 | 모델 | 강의 |
|---|---|---|
| 기준선 | 지난주 그대로(Naive), **작년 같은 주** | W4, W6 |
| 강의 모델 | ARIMA, SARIMA, ARIMAX, SARIMAX (검색 유무 각각) | W7, W9 |
| 강의 모델 보강 | 시계열 회귀(추세 + 푸리에 계절, 로그 변환), Holt-Winters | W4~6 |
| 확장 | 모든 동을 묶은 전역 Ridge·LightGBM, 묶은 형태의 LSTM | W9 + 확장 |

### 3.5 검증

| 질문 | 방법 | 지표 |
|---|---|---|
| ① 정답을 잘 맞히나 | 2024~2025년 안 **여러 예측 시점**에서 13주 예측, 연도별로 나눠 보고. 최종 시험은 2026년 구간에서 모든 선택을 고정한 뒤 한 번만 | WAPE, MASE(작년 같은 주 기준), DM 검정 |
| ② 입력이 도움이 되나 | 같은 모델에서 그 입력만 넣고 빼기. 동별 모델과 전역 모델 두 방식 | 두 방식·여러 시점에서 같은 방향일 때만 "도움 된다" |
| ③ 떠오르는 곳을 맞히나 | 예측으로 뽑은 목록 vs 실제 목록 | 상위 K개 적중률 (Naive·무작위 대비) |
| ④ 외부 근거와 맞나 | 뽑힌 동을 검증 전용 자료와 대조 | 상권 추정매출 변화, 알려진 핫플 |
