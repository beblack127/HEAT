# HEAT 생활이동 예측 실험 정리 (출처별)

작성: 2026-11-16 · 김재현

**공통 조건**
- 정답: 생활이동, 20~39세, 목적 4+5+7(쇼핑·여가·기타), 도착 행정동 기준, 주 단위 일평균
- 지역: 416개 동
- 예측: 13주 앞
- 예측 시점 4개: 2024-10-27, 2025-01-26, 2025-04-27, 2025-07-27
- 오차: 13주 WAPE(%), 낮을수록 좋음. 정답은 보정 전 원래 값과 비교
- 4시점·2시점 평균은 아래 표 참고

### 4시점과 2시점의 차이

| 예측 시점 | 예측하는 13주 | 자료 이상(2024-08~10)의 영향 | 포함 |
|---|---|---|---|
| 2024-10-27 | 2024-11 ~ 2025-01 | 학습 마지막 몇 주가 이상 구간이다. 모델이 튀어 오른 수준을 이어 가며 높게 예측한다 | 4시점 |
| 2025-01-26 | 2025-02 ~ 2025-04 | 직접 영향 없음 | 4시점, 2시점 |
| 2025-04-27 | 2025-05 ~ 2025-07 | 직접 영향 없음 | 4시점, 2시점 |
| 2025-07-27 | 2025-08 ~ 2025-10 | "작년 같은 주"가 바로 이상 구간이다. 작년 값을 쓰는 모델이 크게 틀린다(보정 전 작년 같은 주 49.8%) | 4시점 |

- **4시점 평균:** 네 시점을 모두 평균한 값이다. 자료 문제를 얼마나 잘 견디는지까지 포함한 전체 성능이다.
- **2시점 평균:** 자료 이상이 직접 닿지 않는 두 시점만 평균한 값이다. 자료 문제를 빼고 본 모델 자체의 실력이다.
- 두 기준이 다른 모델을 가리킬 수 있다. 그래서 대표 모델은 "두 기준 모두에서 좋은 모델"로 미리 정했다.
- 예: 작년 같은 주(보정 전)는 2시점에서는 12.0%로 괜찮다. 하지만 2025-07-27이 49.8%라서 4시점은 21.6%가 된다. 자료 보정 효과는 주로 4시점에서 보인다.

## A. 재민 깃(JAEMINII/Time-series-Project)에서 가져와 재현한 실험

**재민 설정**
- ARIMA(0,1,1) 고정, SARIMA(1,1,0)(1,0,0)₁₃ 고정(13주 주기)
- 13주 전 생활이동을 입력으로 넣음
- 검색량은 원래 지수 그대로 사용
- 보정 전 자료, 2025-04-27 시점으로 평가

**재민 2차 초안 숫자 (2025-04-27)**
- ARIMA 19.17%
- SARIMAX + 13주 전 생활이동 18.93%
- 여기에 검색량을 더하면 16.28%

**우리 자료로 재현한 결과**

| 모델 (재민 설정) | 검색 없음 | 검색 있음 |
|---|---|---|
| ARIMA(0,1,1) + 13주 전 생활이동 | 19.3% | 17.7% |
| SARIMA(1,1,0)(1,0,0)₁₃ + 13주 전 생활이동 | 18.7% | 17.1% |

- 재현됨: 2025-04-27에서 검색을 넣으면 오차가 약 1.5%p 줄어든다. 재민 결과와 같은 방향이다.
- 숫자가 조금 다른 이유는 동 집합, 주 단위 정답 정의, 검색량을 붙이는 규칙이 달라서다.

## B. 내가 따로 한 실험

### B1. 정답 정의와 기준선
- 427동 이름표 경계로 맞췄다. 신설동과 용두동은 합쳐서 426개 분석 단위다.
- 주 일평균은 유효한 날이 4일 이상인 주만 쓴다. 199주(2023-01~2026-10)다.
- 기준선은 둘이다: 지난주 값(Naive), 작년 같은 주(364일 전).
- 결과(4시점 평균): 작년 같은 주 21.6%, ARIMA(동별 AIC) 17.3%

### B2. 자료 이상 발견과 보정
- 2024년 8~10월에 서울 전체 생활이동이 1.52배 뛰었다. 같은 기간 카드 매출(음식업)은 0.99배로 그대로였다. 자료 쪽 문제로 보인다.
- 그 구간을 과거 자료만으로 정한 상수 하나로 나눠 보정했다.
- 결과: 작년 같은 주 21.6% → **13.9%**. 가장 큰 개선이다.

### B3. 모델 추가와 결합 (보정 자료)

| 모델 | 4시점 | 2시점 |
|---|---|---|
| 작년 같은 주 (보정) | 13.9 | 12.0 |
| ARIMA (보정) | 13.1 | 13.4 |
| ARIMA + 푸리에 (보정) | 12.7 | 11.8 |
| 작년 같은 주 + Theta 결합 | 12.1 | 11.4 |
| 작년 같은 주 + ARIMA 결합 | **11.7** | 10.7 |
| **작년 같은 주 + ARIMA·푸리에 결합 (대표 모델)** | 11.8 | **10.0** |

- 대표 모델은 미리 정한 규칙(두 기준 모두에서 좋은 모델)으로 골랐다.
- 대표 모델은 작년 같은 주보다 동·시점의 64%에서 더 정확했다(p < 0.001).

### B4. 입력 데이터 시험
- 입력 규칙:
  - 검색량: 서울 대비 비중, 4개월 전 달 값
  - 지하철 하차: 4주 평균, 13주 전 값
  - 음식점 순개업률: 3개월, 4개월 전 달 값
- 보정 전 자료, ARIMAX 7개 조합: 가장 좋은 조합(개폐업) 17.27% vs 입력 없는 ARIMA 17.32%. 차이가 거의 없다.
- 보정 자료, ARIMA·ARIMA+푸리에·SARIMA에 각 7개 조합:
  - 입력 없음이 가장 좋다(11.67%).
  - 검색이 들어간 조합은 유의하게 나빠진다.
  - 지하철·개폐업은 넣으나 안 넣으나 같다.

### B5. 핫스팟 판정과 시스템
- 현재 핫스팟: 13주 평균 상위 10%
- 떠오르는 곳: 1년 전 같은 13주 대비, 서울 대비 비중 증가율 상위 10%
  - 규모 하한은 2023년 하위 25%(약 2,050명/일)로 고정했다.
  - 하한을 시점마다 다시 계산해도 목록의 93%가 같다.
- 떠오르는 곳 상위 10% 적중률: 모델 58%, 지속(지금 그대로) 53%, 무작위 10%
- 현재 핫스팟 적중률: 모든 방법이 약 95%
- HEAT_system.html: 핫플지수 지도, 가장 핫한 곳 10곳, 가장 떠오르는 곳 10곳, "생활이동만 vs 우리 자료" 비교

## C. 재민 설정 + 내가 추가한 실험

### C1. 전체 조합 실험
- 요인:
  - 자료: 보정 전 / 보정 후
  - 모델: 계절 없음, 13주 계절, 52주 계절
  - 차수: 고정 / AIC
  - 검색: 없음, 원래 지수, 서울 대비 비중
  - 13주 전 생활이동 입력: 없음 / 있음
  - 작년 같은 주와 결합: 안 함 / 함
- 의미가 적은 조합은 뺐다: 13주 계절 + AIC, 보정 후 자료에서 재민 재현용 조건.
- 재민 설정에서 시작해 한 가지씩 고쳤다(사다리):

| 단계 | 04-27 검색X | 04-27 검색O | 2시점 검색X | 2시점 검색O |
|---|---|---|---|---|
| 0 재민 설정 | 18.7 | **17.2** | 20.7 | 19.9 |
| 1 52주 계절 | 18.0 | 31.1 | 19.8 | 26.6 |
| 2 차수 AIC | 14.3 | 27.6 | 15.2 | 22.0 |
| 3 검색을 서울 대비 비중으로 | 14.3 | 17.9 | 15.2 | 17.1 |
| 4 자료 보정 | 11.9 | 14.9 | 13.9 | 15.5 |
| 5 작년 같은 주와 결합 | **8.1** | 9.0 | **10.8** | 11.3 |

- 재민 설정에서는 검색이 2025-04-27 오차를 줄인다. 하지만 4시점 평균으로는 22.7% → 23.7%로 나빠진다.
- 모델을 고친 뒤(1단계부터)에는 모든 단계에서 검색 없는 모델이 더 좋다.
- 전체 최저: 보정 + ARIMA(AIC) + 입력 없음 + 결합, 11.68%. 대표 모델과 사실상 같다.

### C2. 가짜 입력 실험
- 재민 설정(13주 계절, 고정 차수, 13주 전 생활이동 포함)에 입력을 하나씩 넣었다.
- 가짜 입력: 다른 동의 검색 지수(동 순서를 시드 42로 섞음)

| 입력 | 2025-04-27 | 4시점 | 04-27 좋아진 동 | p (04-27) |
|---|---|---|---|---|
| 없음 | 18.7 | 22.7 | – | – |
| 자기 동 검색 | 17.1 | 23.6 | 52% | 0.47 |
| 다른 동 검색 (가짜) | 19.0 | 23.7 | 47% | 0.30 |
| 지하철 | 18.4 | 23.0 | 51% | 0.07 |
| 개폐업 | 19.7 | 22.8 | 54% | 0.60 |

- 자기 동 검색은 2025-04-27에서 가짜보다 낫다. 순수한 우연만은 아니다.
- 하지만 좋아진 동이 52%뿐이고 동별 검정도 유의하지 않다. 일부 큰 동에서만 나아졌다.
- 4시점 평균으로는 자기 동 검색이나 가짜 검색이나 둘 다 오차를 약 1%p 늘린다.

## 최종 결론

1. **성능 향상은 자료 보정과 작년 같은 주 결합에서 나왔다.** 작년 같은 주 21.6% → 대표 모델 11.8%로, 오차가 거의 절반이 됐다.
2. **동별 시계열 모델에 검색량·지하철·개폐업을 넣는 방식으로는 오차가 줄지 않는다.** 재민 실험의 검색 효과는 재현됐다. 하지만 그 효과는 약한 기준 모델과 한 시점(2025-04-27), 일부 동에서만 나타난다.
3. **"어디가 떠오르는가"는 아직 어렵다.** 떠오르는 곳 상위 10% 적중률이 모델 58%, 지속 기준 53%로 조금 나은 수준이다. 현재 핫스팟은 모든 방법이 약 95%를 맞힌다.
