# WAPE 말고 무엇으로 평가할까: 지표 비교 (2026-11-27)

## 왜 했나

WAPE는 큰 동과 서울 전체 수준이 좌우해서, "어디가 뜨는가"를 잘 맞히는지 보여 주지 못한다는 의심이 있었다. 모델을 새로 학습하지 않고, 성격이 다른 단순 기준선 6개를 여러 지표로 채점해서 **지표끼리 순위가 같은지, 어떤 지표가 무엇을 구분하는지** 봤다.

## 설정

- 정답: 생활이동 20~39세, 목적 4+5+7, 도착 행정동, 주(월~일) 일평균. 424개 동(모든 날 자료가 있는 동), 2023-01-02 ~ 2025-08-25, 139주
- 예측: 13주 앞, 예측 시점 4주 간격 13개(2024-06-24 ~ 2025-05-26). 이 중 쓰는 창(미래, 그 1년 전, 최근 13주, 그 1년 전)에 2024-08~10이 없는 시점 4개를 따로 집계
- 변화 지표는 규모 하한(2023년 하위 25% 제외) 318개 동에서 계산
- 기준선 (학습 없음)

| 기준선 | 예측 |
|---|---|
| last_week | 마지막 주 값을 13주 동안 유지 |
| mean_last_13w | 최근 13주 평균 |
| same_week_last_year | 52주 전 같은 주 |
| same_week_last_year_x_seoul_trend | 위 값 × 서울 전체의 최근 13주 / 1년 전 같은 13주 비율 |
| share_momentum | 1년 전 같은 13주 비중 × exp(최근 13주 변화), 서울 합계는 위 값 |
| avg(last_year, mean_13w) | 작년 같은 주와 최근 13주 평균의 1:1 평균 (중간발표 대표 모델의 단순판) |

- 지표

| 지표 | 뜻 | 좋은 방향 |
|---|---|---|
| WAPE | Σ\|오차\| / Σ실제. 큰 동이 크게 반영 | 낮을수록 |
| MASE | 동마다 오차를 "그 동의 작년 같은 주 예측 오차(학습 구간)"로 나눈 뒤 평균. 동마다 같은 가중치 | 낮을수록 |
| median_dong_WAPE | 동별 WAPE의 중앙값 | 낮을수록 |
| share_WAPE | 서울 대비 비중으로 바꾼 뒤의 WAPE. 서울 전체 수준 오차를 뺀 값 | 낮을수록 |
| level_rank_spearman | 13주 합의 동 순위 상관 | 높을수록 |
| hot_P@10 | 예측 상위 10% 중 실제 상위 10% 비율 (현재 핫플) | 높을수록 |
| change_spearman | 예측한 비중 변화 g와 실제 g의 순위 상관 | 높을수록 |
| emerging_P@10 | 예측 g 상위 10% 중 실제 g 상위 10% 비율 (떠오르는 곳) | 높을수록 |

## 해석

1. **수준 지표와 변화 지표가 서로 다른 기준선을 1등으로 뽑는다.** WAPE·MASE·share_WAPE는 1:1 평균이 가장 좋고, 변화 순위 상관·떠오르는 곳 적중률은 last_week가 가장 좋다. WAPE가 좋다고 떠오르는 곳을 잘 잡는 게 아니라는 직접 증거다.
2. **작년 같은 주는 WAPE로는 2등이지만 떠오르는 곳을 하나도 고르지 못한다.** 수준만 보는 평가는 이런 모델을 좋게 평가한다.
3. **수준 순위 상관(0.99)과 hot_P@10(0.93~0.95)은 모든 기준선이 거의 같다.** 현재 핫플은 무엇으로 해도 맞힌다. 모델 비교 지표로는 쓸모가 없다.
4. **MASE는 동마다 같은 가중치라 WAPE를 보완한다.** WAPE와 순서는 거의 같지만, 작은 동에서 크게 틀리는 모델을 잡아낸다(서울 추세 보정판 MASE 2.06).
5. **share_WAPE는 서울 전체 수준 오차를 빼고 본다.** 이상치·계절처럼 서울 공통 부분을 맞힌 효과가 빠져서, 동별 배분을 얼마나 잘 맞혔는지 보여 준다.

## 제안: 팀 공통 평가 지표

| 무엇을 보나 | 지표 | 기준선 |
|---|---|---|
| 수준 (크게 틀리지 않나) | WAPE + MASE | 작년 같은 주, 1:1 평균 |
| 동별 배분 | share_WAPE | 1:1 평균 |
| 떠오르는 곳 | 변화 순위 상관 + emerging_P@10 | last_week(모멘텀) |

현재 핫플 지표(hot_P@10, 수준 순위 상관)는 보고만 하고 비교에는 쓰지 않는다.

## 한계

- 학습한 모델은 없다. 기준선끼리의 비교라, 지표의 성질을 보는 실험이다.
- 이상 구간 없는 시점은 4개뿐이다.
- 자료가 2025-08까지라 2025년 하반기 시점은 없다.
