# 4+5+7 생활이동 전체 시계열과 생활이동 단독 ARIMA 계열

## 그래프 범위

1. `01_all_collected_457.png`: 수집된 **32개월·974일**(2023-01-01~2025-08-31)의 목적 4+5+7 도착 행정동 추정 이동량 합계. 20대, 30대, 전 연령을 구분해 표시했다. 기간 전체에 **429개 동 코드**가 등장하지만 하루에는 **426~427개 코드**가 관측된다. 결측 동·일은 0으로 채우지 않았다.
2. `02_all_424_dong_heatmap.png`: 139개 완전한 주의 이력이 있는 **424개 동 전체**. 각 동 주간 일평균을 자기 동의 기간 중앙값으로 나눠 상대적 변화를 나타냈다. 색은 절대 이동량 크기가 아니다.
3. `03_acf_pacf.png`: 424개 동을 합한 주간 20·30대 목적 4+5+7 시계열의 로그 수준 및 로그 1차 차분 ACF/PACF. 139주 전체를 썼다. 로그 수준은 가까운 시차의 자기상관이 크고, 1차 차분에서는 많이 줄어든다. **2024년 8~10월 광범위한 급증**이 포함돼 있으므로 이 그림만으로 계절 주기나 정상성을 확정하지 않는다.
4. `04_four_model_forecasts.png`: 같은 424개 동 합계에 대한 ARIMA, SARIMA, ARIMAX, SARIMAX의 **13주 뒤** 순차 예측. 이는 **서울 합계 한 개의 시계열** 모델이며 동별 모델 424개의 성능이 아니다.

## 모델 설정

| 이름 | 비계절 차수 | 13주 계절 차수 | 외생변수 |
|---|---|---|---|
| ARIMA | (0,1,1) | 없음 | 없음 |
| SARIMA | (1,1,0) | (1,0,0,13) | 없음 |
| ARIMAX | (0,1,1) | 없음 | **동일 생활이동 시계열의 13주 전 값** |
| SARIMAX | (1,1,0) | (1,0,0,13) | **동일 생활이동 시계열의 13주 전 값** |

외생변수도 생활이동 원자료에서만 만든다. 목표 주 `T`의 `T−13주` 이동량은 예측 원점에 이미 관측되어 있으므로 미래 실제값을 사용하지 않는다. 네 모델 모두 **같은 80주 학습 구간**과 종속변수 `log1p` 변환을 사용하고 결과를 역변환했다. 첫 예측 주(2025-01-06)의 원점인 **2024-10-07까지** 계수를 적합하고, 매주 새로 확인된 한 주의 이동량으로 상태만 갱신했다. 주별 재적합이나 평가 기간의 계수 재선택은 하지 않았다. 13주 계절 차수는 **탐색적 설정**이며 ACF가 이를 확증하지는 않는다. 예측 그래프의 **파란색은 관측값, 빨간색은 13주 앞 예측값**이다.

| 2025년 WAPE | 1~7월 30주 | 1~8월 34주 |
|---|---:|---:|
| 전년 같은 주 기준선 | **9.72%** | 14.92% |
| ARIMA | 16.12% | 14.84% |
| SARIMA | 16.16% | 14.88% |
| ARIMAX | 15.36% | **14.16%** |
| SARIMAX | 15.60% | 14.38% |

**1~7월에는 네 모델이 모두 전년 같은 주 기준선보다 나쁘다.** 1~8월 기준선의 악화에는 2024년 8월 원자료 급증을 2025년 8월과 비교하는 영향이 크다(8월 기준선 WAPE 56.64%). 네 모델의 우열 차이도 작고, 2024년 8~10월 원자료 급증이 최초 적합 자료에 들어가 있다. 검색량·지하철·생활인구는 이 네 모델에 전혀 사용하지 않았다.

이 WAPE는 **동별 오차를 합산한 기존 424동 평가 WAPE와 계산 단위가 다르다.** 서울 전체 실제 합계와 예측 합계의 차이를 재므로 동별 과대·과소 예측이 서로 상쇄될 수 있다. 동별 핫플 후보 선별 성능을 이 표로 주장할 수 없다.
