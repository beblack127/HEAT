# Mobility pilot snapshot

This directory preserves the scripts, reports, aggregate input tables, prediction tables, and figures from the 2026-11-16 workspace. The most relevant current experiment is [`fixed_origin_search/README.md`](fixed_origin_search/README.md): a fixed 13-week forecast from 2025-04-27 on the same 419 dongs for every comparison. Older monthly and 40-dong pilot folders remain here as experiment history; their metrics should not be mixed with the fixed-origin result.

The three largest prediction CSVs are stored losslessly as `.csv.gz`. Decompress them before rerunning a script that expects a plain `.csv` file. Rebuildable per-dong model caches, Python caches, and raw Naver API response batches were omitted. The scripts also refer to the separately maintained HEAT repository (`work/HEAT`) and Seoul source files that are not part of this snapshot. This snapshot supports review of the recorded results; full source-data reproduction requires those inputs.

Presentation examples are in [`presentation/`](presentation/). The diagnostic WAPE values for Hwagok 1-dong and Ichon 2-dong are in [`fixed_origin_search/case_diagnosis/model_case_metrics.csv`](fixed_origin_search/case_diagnosis/model_case_metrics.csv).
