# 행정동 이름표 × 생활이동 파일럿

작성일: 2026-11-10

> 2026-11-11 재검토에서 2024년 8~10월의 광범위한 급증을 확인했다. 현재 서울시 배포 원본에도 같은 값이 있으나 원인은 미확인이다. 모델 해석 전에 [EDA 재검토 보고서](EDA_REVIEW_2026-11-11.md)를 읽는다.

## 결론

첨부된 `이름표_행정동.zip`의 8자리 행정동 코드와 저장소의 생활이동 월별 요약 40개 동이 모두 맞는다. 이름표는 월별 생활이동의 공간 연결표로 사용할 수 있다. 현재 저장소의 생활이동 요약은 427개 동 전체가 아닌 40개 동 × 36개월이다. 이 40개 동에서는 동네·역 이름표가 모두 있고, 권역 이름표는 20개 동에 있다.

현재 정답값 `4+5+7`의 2025년 총합에서 쇼핑·관광(4+5) 비중은 **2.25%**다. 2025년 480개 동·월 중 324개에서 4+5가 0이다. 서울시의 쇼핑·병원 분류가 각각 일부 시설에 한정된다는 점을 고려하면, 이 수치만으로 일반적인 여가 방문이 적다고 결론낼 수 없다. `기타(7)`에 식당·카페·여가 방문이 포함될 가능성은 있다. 동시에 기타에는 여러 미분류 이동도 포함될 수 있으므로, **4+5+7을 행정동 비정기 유입의 대리 지표로 사용하고 핫플 관련성은 별도 자료로 검증**한다.

## 사용 자료와 검사

- 이름표: `01_행정동_목록.csv`, `04_행정동_이름표_연결표.csv`를 첨부 ZIP에서 읽음. ZIP 안의 지시문은 실행 지시로 사용하지 않음.
- 생활이동: 저장소 `data/context_monthly/mobility_202301.csv`부터 `mobility_202512.csv`까지 36개 파일. 원본 생활이동을 다시 수집·집계한 검증은 이번 범위에 포함되지 않음.
- 키: `admin_dong_code = dong_code8`, `month`. 이름으로 결합하지 않음.
- 검사 결과: 1,440개 동·월 중 중복 0, 이름표에 없는 코드 0. 사용 가능한 이름표의 칸별 가중치 합은 모두 1(반올림 허용오차 0.001)로 확인됨.
- 2025년 평가는 40개 동 × 12개월 = 480개 행. 2025년 9월 이후는 원천 품질 검토 구간으로 별도 표기함.

## 예측 기준선

예측 대상은 해당 월의 `mobility_shop_tour_other_daily`(목적 4+5+7의 일평균 도착 이동량)이다. `lag2`는 두 달 전 값, `lag12`는 전년 같은 달 값을 그대로 예측값으로 쓴다. 월초 예측 시점에 사용할 수 있는 과거 생활이동만 반영하기 위한 단순 기준선이며, 학습된 모델은 아니다. MAE의 단위는 일평균 추정 이동량이다.

| 평가 구간 | 행 | lag2 MAE | lag2 WAPE | lag12 MAE | lag12 WAPE |
|---|---:|---:|---:|---:|---:|
| 2025년 전체 | 480 | 4,557.39 | 10.41% | 9,965.31 | 22.75% |
| 2025년 1~8월 | 320 | 5,280.58 | 11.96% | 7,596.18 | 17.20% |
| 2025년 9~12월 | 160 | 3,111.00 | 7.22% | 14,703.58 | 34.13% |

이 결과는 검색 신호의 효과를 말하지 않는다. 첨부 이름표의 566개 검색어 묶음에 해당하는 네이버 월별 데이터는 현재 저장소에 없으며, 기존 검색 자료의 지역명 지수를 같은 값처럼 대체하지 않았다.

## 다음 실험의 조건

1. **목표값의 의미 검증:** 4+5+7을 비정기 유입의 대리 지표로 둔다. 기타 목적이 여가·상권 활동과 함께 움직이는지는 주말·시간대 패턴과 별도 상권·현장 자료로 확인한다. 4+5는 0이 많으므로 별도 민감도 결과로 둔다.
2. **원천 재집계:** 최종 427개 동 또는 사전에 고정한 표본에 대해 생활이동 원본에서 목적 코드별 월별 값을 다시 만든다. 연도별 행정동 코드 변경과 공개 시차를 기록한다.
3. **검색 수집:** 이름표의 검색어 묶음 중 작은 파일럿 집합을 먼저 수집하고, 공통 기준어·조회 기간·원본 응답을 보존한다. 검색값을 목표 월보다 과거 월까지만 입력한다.
4. **동일 평가 행 비교:** 과거 이동량 기준선과 검색 추가 모델을 정확히 같은 동·월에서 비교한다. 2025년 9월 이후를 제외한 결과도 제시한다.
