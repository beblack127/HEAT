# 중간발표용 전체 파이프라인과 6장 슬라이드 구성

2026-11-14 기준. 팀 #14 발표: 11월 19일(목), 5분 + 질의응답 3분. 열람 가능한 슬라이드 링크 제출: 11월 16일(월) 23:59.

## 발표의 한 문장

> **서울 행정동의 비정기 목적 도착 생활이동을 예측하고, 검색 관심과 음식점 변화가 과거 이동량만 사용한 모델보다 도움이 되는지 검증한다.**

검색량·음식점 개폐업 *자체*를 예측한 팀원 리포트는 보조 연구 성과다. 그 리포트의 성능을 생활이동 GT에 대한 성능으로 합치지 않는다.

## A. 전체 연구 파이프라인

### 1. 단위와 목표 고정

- 관측 단위: 공식 행정동 코드 `d` × 월 `m`. 2025-12 기준 이름표의 427개 동은 공간 연결 기준이다. 과거에 없던 신설동·용두동의 2023~2025 과거 개별값을 임의로 생성하지 않는다.
- GT: 서울시 **내국인·도착지 기준 목적 4(쇼핑)+5(관광)+7(기타)** 이동의 월 일평균 `y[d,m]`. `기타`가 넓어서 실제 여가 방문자 수라고 단정하지 않는다. 목적 4+5만의 민감도도 본다.
- 예측 과제: 목표 월 `m`의 **한 달 이동량**. 매월 1일을 예측 시점으로 놓고 우선 `m-2`까지 관측된 값만 쓴다. 이 설정은 팀원 리포트의 ‘다음 3개월 검색 평균/음식점 합계 예측’과 다르다.
- 결과 해석: `y`의 규모가 큰 동과 **증가한 동**을 나눠 보고한다. 단기 급증은 지속 성장과 분리한다.

### 2. 데이터 표 만들기

```
공식 월별 행정동 코드 ─┐
이름표 ZIP의 동·역·검색어 연결 ─┼─> 동×월 패널
생활이동 목적별 일자료 ─┘          ├─ y: 목표 월 생활이동
검색·음식점·역·생활인구 ───────────└─ X: 예측일 이전에 확인된 과거값
```

| 자료 | 사용 방법 | 현재 발표에서의 상태 |
|---|---|
| 목적별 생활이동 | **GT와 과거 `y` 시계열**. 목적 4+5+7, 일수를 나눠 월 일평균 | 기존 40동 패널·모형 결과 있음. 427동 전체 패널은 진행 중 |
| 427동 이름표 ZIP | 현재 동 코드, 검색어 별칭·가중치, 주변 역·상권 연결 | 427동 연결 CSV 완성. 과거 코드 변화 대조 필요 |
| 검색량 | 동별 이름표 가중치로 묶어 과거 검색 수준/변화 1개씩 후보 X | 팀원 PDF에는 422동 결과가 있으나 현재 작업 저장소에는 해당 월별 CSV 없음. **생활이동 효과 미검증** |
| 음식점 인허가 | 좌표→동, 영업 점포의 12개월 변화 또는 개폐업 요약을 과거 X로 사용 | 팀원 PDF에는 427동 결과가 있으나 현재 작업 저장소에는 월별 표 없음. **생활이동 효과 미검증** |
| 역 하차량 | 월 일평균 하차량을 이름표의 주변 역 연결로 동에 집계, 과거 X 후보 | 2023~25 역 원자료 있음. 2026 및 역 변천 점검 필요 |
| 생활인구 | 과거 낮 시간대 월평균 X | **현재 40동 ARIMAX/SARIMAX 파일럿의 X**. 기존 행정동 자료 생산은 2026-07 종료되어 최종 주 모형의 필수 변수로 두지 않음 |
| 분기 상권 자료·S-DoT | 외부 확인 또는 설명 | 월별 주 GT·초기 모형 입력에 넣지 않음 |

### 3. 모델과 검증

- 먼저 `y_(m-2)`와 `y_(m-12)` 두 단순 기준선. 그다음 동별 ARIMA·SARIMA(과거 `y`만), ARIMAX·SARIMAX(같은 `y`에 관측된 과거 X **한 개** 추가). X를 넣고 뺀 차이는 **동일 동·월**에서 비교한다.
- 현재 파일럿은 **40동**, 고정 차수 적합 2023-03~2024-11, 목표월 2025-01~12의 2개월 앞 rolling 예측. 발표 주 결과는 공식 품질 이슈 이전인 **2025-01~08, 320 동·월**만 사용한다. 별도 검증 기간을 거쳐 선정한 최종 차수가 아니므로 ‘초기 백테스트’라고 부른다.
- 최종 연구 *계획*: 생활이동 2023~24년 초기 학습 → 2025-01~08 개발 검증 → 2026-01~10 최종 시험 후보. 단, 2024-08~10 광범위한 급증과 2025-09 이후 원천 차이를 먼저 점검한다. 검색·음식점은 공개일·수정일을 기록하고 원자료에서 2개월 전 값만 사용한다.
- 평가: 수치 오차는 WAPE·MAE, 장소 후보는 상승 상위 K개 적중률. WAPE가 낮을수록 좋다. 큰 동의 영향이 크므로 동별 오차도 함께 본다. top-K와 2026 최종 시험은 **지금 발표 결과가 아니라 계획**이다.

### 4. 현재 확인된 결과와 한계

2025-01~08, 동일한 40동×8개월=320 평가 행의 WAPE:

| 입력 | 모형 | WAPE |
|---|---|---:|
| 생활이동만 | `m-2` 단순 기준선 | 11.96% |
| 생활이동만 | 전년 동월 기준선 | 17.20% |
| 생활이동만 | ARIMA | 10.91% |
| 생활이동만 | SARIMA | **10.89%** |
| 생활이동 + 2개월 전 낮 생활인구 | ARIMAX | 11.54% |
| 생활이동 + 2개월 전 낮 생활인구 | SARIMAX | 11.75% |

**현재 부정적 결과:** 생활인구를 추가했지만 오차가 줄지 않았다. 네이버나 음식점 X를 넣은 결과는 아니다. 40동은 재현의 427동 이름표에서 선정된 표본이 아니라 기존 저장소 장소 연결표의 파일럿이다. 목적 4+5가 파일럿의 4+5+7에서 약 2.25%이고, `기타`가 대부분이다. 2024년 8~10월 이동량 급증 원인은 미확인이다. 결과를 서울 전체 최종 성능으로 발표하지 않는다.

## B. 발표 슬라이드: 6장·5분

**원칙:** 각 장에 주장 한 줄 + 그림/숫자 하나. 문장형 표와 모델별 설명은 말하거나 발표자 메모에 둔다. 발표 후 최종 보고서가 있으므로 중간발표에는 검증 가능한 진행 상황만 보여 준다.

| 장 / 시간 | 제목 | 화면에 남길 것 | 발표자가 말할 것 |
|---|---|---|---|
| 1 / 25초 | 연구 질문과 팀 역할 | “어느 행정동의 비정기 목적 이동이 늘어날까?” + **팀원 이름→실제 산출물** 한 줄씩 | 역할은 팀에서 확인한 기여만 적는다. |
| 2 / 50초 | 제안 피드백과 정의 | **기간 그림:** 보조 연구 `2022~25 / 다음 3개월 묶음` ↔ 주 연구 `2023~26 / 한 달 목표·2개월 전 정보`. 아래에 `규모 / 지속 성장 / 일시 급증` 세 작은 시계열 모양 | 2022 시작은 검색 자료의 시작에 맞춘 보조 연구의 공통 기간. ‘3개월’은 미래 3개월 평균·합계이며 특정 3개월 뒤 한 달이 아님. 생활이동 연구와 구별. 일시 급증은 재하락까지 확인해야 하며 현재 2024년 급증은 **후보**임. 슬라이드 텍스트를 줄이라는 피드백은 덱 전체에 적용. |
| 3 / 55초 | 데이터와 진행 상황 | **한 방향 파이프라인:** `생활이동 y + 이름표/과거 X → 동×월 표 → 예측`. 아래 작은 상태표: `427동 연결 완료 / 40동 모델 완료 / 427동 모델·검색 결합 진행 중` | 검색·음식점은 별도 GT가 아니라 미래 이동량을 예측하는 과거 보조 지표. 발표된 검색·개폐업 자체의 예측은 다른 실험이라고 분명히 말함. |
| 4 / 45초 | 초기 모델과 평가 | **시간축 하나:** `2023-03~2024-11 적합 → 2025-01~08 초기 평가`. 아래 `lag2·lag12 / ARIMA·SARIMA / ARIMAX·SARIMAX(+생활인구)` | 월초에 두 달 전까지 알고 있다고 가정. 네 모형 모두 생활이동 한 값을 예측. 초기 고정 차수 파일럿이라 독립 train/validation/test 최종 성능이 아님. |
| 5 / 80초 | 40동 초기 결과 | **6개 가로 막대:** 기준선 11.96·17.20, ARIMA 10.91, SARIMA 10.89, ARIMAX 11.54, SARIMAX 11.75. 제목은 “생활인구 추가는 오차를 줄이지 못했다”. 각주 `40동, 2025-01~08, WAPE↓` | SARIMA와 ARIMA 차이는 매우 작음. ARIMAX/SARIMAX의 X는 **생활인구**, 검색이 아님. 부정적 결과를 이유와 함께 보고하되 원인을 단정하지 않음. 2024 급증과 짧은 이력 가능성을 언급. |
| 6 / 45초 | 남은 작업과 최종 검증 | **세 단계 시간축:** `427동 패널 완성 → 검색·음식점 X 추가 → 2026 시험`. 아래 한 줄 `품질 점검 후 같은 동·월에서 기준선 대비 효과 확인` | 기대 결과는 “어떤 신호가 추가로 도움이 되는지 확인”이지 성능 개선을 보장하는 것이 아님. 2025-09 이후 자료 차이, 과거 동 경계, 원본 공개 시점이 검증 관문. |

### 슬라이드에 넣지 말 것

- 17쪽 팀원 리포트의 표 전체, 검색·개폐업 목표의 MASE를 생활이동 결과 옆에 배치하는 것.
- 현재 만든 두 칸짜리 2025 전체/1~8월 차트 그대로 사용. 발표에는 **1~8월만** 보이게 다시 그리거나 해당 데이터로 간결한 차트를 만든다. 2025-09 이후 원천 품질이 별도 점검 대상이기 때문이다.
- `temporal spike`의 임시 50%/복귀 10% 수치를 확정 규칙으로 크게 표기하는 것. 본문에는 ‘일시 급증 후 복귀, 데이터 품질 확인’만 놓고 수치는 질문 대비 메모에 둔다.
- 427동 네 모형 성능, 검색·음식점→생활이동 성능, 2026 최종 시험을 이미 완료한 것처럼 표현하는 것.

### 팀원에게 받아야 완성되는 부분

1. **실제 팀 역할·기여**와 제안 발표 때 받은 코멘트의 원문 또는 정확한 요약. 현재 확인된 코멘트는 ‘정의 상세화’와 ‘발표 슬라이드 텍스트 축소’ 두 가지다.
2. 검색 422동 월별 CSV와 음식점 427동 월별 CSV, 생성 코드·공개 기준일. 발표일까지 결합하지 못하면 다음 단계로 표시한다.
3. 보조 연구에서 **왜 최초 계획의 기본 예측 기간을 3개월로 정했는지** 담당자의 설명. 리포트에는 3·6·12개월 비교와 결과가 있지만, 최초 선택 이유는 적혀 있지 않다.
