# 행정동별 생활이동 단독 ARIMA 계열 비교

> **평가 질문 변경:** 이 폴더는 매주 새 관측값을 반영하는 rolling 13주 선행 실험이다. 사용자가 의도한 **한 번의 예측 시점에서 다음 3개월 전체를 예측**하는 결과는 [고정 원점 실험](../fixed_origin_3month/README.md)을 사용한다. 아래 수치를 그 결과로 인용하지 않는다.

## 왜 동별로 바꿨나

서울 합계 한 시계열에서는 어떤 동의 과대 예측과 다른 동의 과소 예측이 상쇄된다. 프로젝트의 목적이 **어느 행정동의 방문 활동이 늘어나는가**이므로, 각 동에 모델을 별도로 적합하고 **동·주별 절대오차를 합산**해서 평가했다. 앞선 서울 합계 그래프는 전체 추세와 원자료 이상을 설명하는 EDA로만 사용한다.

## 공통 설정

- 데이터: 도착 행정동 목적 4+5+7, 남녀 20·30대 주간 일평균 **추정 이동량**. 완전한 139주를 가진 **424개 동**. 원자료에서 등장한 전체 코드 429개와 구별한다.
- 모델: 동별 ARIMA(0,1,1), SARIMA(1,1,0)×(1,0,0,13), ARIMAX(0,1,1), SARIMAX(1,1,0)×(1,0,0,13). ARIMAX/SARIMAX의 유일한 외생변수는 **같은 동의 13주 전 생활이동량**이다. 네 모델 모두 **같은 80주 학습 이력**을 사용한다.
- 예측: 목표 주를 13주 앞에서 예측. 2025-01-06의 최초 원점은 2024-10-07. 계수를 이 원점까지로 적합하고, 매주 새로 알게 된 실제 이동량으로 상태만 갱신한다. 미래 실제 타깃·검색·지하철·생활인구는 사용하지 않는다.
- 평가: 2025년 1~8월 34주, 그중 1~7월 30주를 별도로 표시. 기준선은 **전년 같은 주 이동량**. WAPE = `동·주별 |실제−예측|의 합 / 동·주별 실제값의 합`.
- 기존 40개 동 파일럿과 **파일럿 밖까지 포함한 424개 동 전체**를 각각 집계했다. 모델의 차수는 수업 범위 안의 탐색적 설정이다.

## 동별 평가 결과

| 평가 동·기간 | 전년 같은 주 | ARIMA | SARIMA | ARIMAX | SARIMAX |
|---|---:|---:|---:|---:|---:|
| **40동, 2025년 1~7월** | **13.44%** | 22.07% | 22.70% | 22.20% | 21.98% |
| **424동, 2025년 1~7월** | **13.77%** | 19.63% | 20.40% | 19.94% | 19.33% |
| **424동, 2025년 1~8월** | 18.62% | 18.65% | 19.38% | 18.95% | **18.36%** |

**1~7월에는 네 모델 모두 계절 기준선보다 나쁘다.** 1~8월에 SARIMAX가 0.26%p 앞서는 수치는 2025년 8월의 기준선 WAPE가 **57.48%**로 급등한 데 크게 좌우된다. 그 기준선은 원인 미확인인 2024년 8~10월 생활이동 급증 구간을 참조한다. 이를 근거로 SARIMAX가 우승했다고 말하면 부정확하다. 2025년 자료는 이전 실험에서 이미 탐색했으므로 최종 untouched test로 부르지 않는다.

424개 동 중 1~7월 **SARIMAX가 전년 기준선보다 절대오차가 낮은 동은 97개**다. ARIMA 92개, SARIMA 92개, ARIMAX 94개다. 검색량이나 지하철을 넣기 전에, **생활이동만 쓰는 수업 모델의 어려움**과 강한 계절 기준선이 확인된 셈이다. 여기에 부가 변수를 넣더라도 기준선을 넘어야 개선이라고 할 수 있다.

동별 ACF/PACF에서도 차이가 보인다. 로그 수준의 ACF 1주 시차 중앙값은 **0.788**이지만 13주 시차는 **−0.043**, 52주 시차는 **0.005**다. 로그 1차 차분 후에는 1주 시차 ACF 중앙값이 **−0.188**이다. 424개 동 분포가 넓어서 **한 가지 계절 차수로 모든 동을 설명하기 어렵다.** 단, 139주와 2024년 원자료 급증 때문에 52주 자기상관 추정도 불안정하다.
