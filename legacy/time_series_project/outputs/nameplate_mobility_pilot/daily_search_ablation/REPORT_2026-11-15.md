# 일별 네이버 검색 × 20·30대 생활이동: 예비 실험

2026-11-15. **검색 API 수집과 탐색적 feature 비교**까지 완료했다. 실제 검색 횟수나 고유 방문자 수를 측정한 결과는 아니다.

## 데이터와 확인

- [NAVER API HUB 검색어 트렌드](https://api.ncloud-docs.com/docs/naver-api-hub-search-trend)에 `timeUnit: date`로 2023-01-01~2025-08-31의 **974일**을 다시 요청했다. 기존 HEAT의 행정동 이름표 연결과 제외 규칙을 그대로 사용했다. 기존 40개 동에 필요한 138개 검색어 묶음(443조각)을 각 연령 조건별 111회 요청에 나눠 수집했다. 원응답은 각각 `daily_search_40/raw`, `daily_search_19to39_40/raw`에 저장했으며 인증키는 저장하지 않았다.
- **전 연령 검색**과 NAVER 연령 구간 `3,4,5,6`인 **19~39세 검색**을 따로 받았다. [API의 연령 구간](https://api.ncloud-docs.com/docs/naver-api-hub-search-trend)은 19~24세부터 시작해서 19세를 제외할 수 없다. 생활이동 타깃은 20~39세이므로 완전히 같은 연령대가 아니다.
- 검색 지수는 2023년 기준 문래 검색어 조각의 평균을 100으로 놓은 상대값이며, 실제 검색 건수도 서울 전체 검색 비중도 아니다. 2023년 기준값만으로 요청 간 척도를 맞췄다. 각 동의 이름표 가중치로 동·역·권역 값을 만든 후 있는 칸들의 평균을 구했다. 동별 검색 결측은 없다.
- 전 연령 일별 검색을 월평균으로 바꾸면 기존 HEAT 월별 지수와 전체 상관계수 **0.9985**, 동별 시계열 상관계수 중앙값 **0.9809**다. 두 API 요청의 정규화 방식이 달라 값 자체가 정확히 같지는 않다.
- 타깃: 서울시 일별 도착 행정동의 4+5+7 목적 **20·30대 추정 이동량**. 40개 동 × 2025-01-01~08-31 = **9,720 동·일**을 같은 표본으로 평가했다.

## 검색을 추가했을 때

동별 시차 이동량, 요일·월, 동 고정효과를 사용하는 단순한 풀링 Ridge 모델을 만들었다. 검색 추가 모델에는 예측 시점에 알 수 있는 검색 지수와 최근 7일 평균·주간 변화를 더했다. 모델 계수와 표준화는 **2025년 첫 예측 원점보다 이전** 자료에서만 적합했다. 정규화 강도는 고정했고 시험 구간에 맞춘 튜닝은 하지 않았다. 아래 WAPE는 낮을수록 좋다.

| 이동량 예측 시점 | 단순 요일 기준선 | 검색 없는 학습 모델 | 전 연령 검색 추가 | 19~39세 검색 추가 |
|---|---:|---:|---:|---:|
| 같은 날 추정* | **12.31%** | 15.41% | 14.71% | 12.75% |
| 1일 앞 | **12.31%** | 15.46% | 15.57% | 15.46% |
| 7일 앞 | **12.31%** | 19.19% | 19.30% | 19.29% |
| 30일 앞 | **17.95%** | 26.15% | 26.35% | 26.37% |
| 91일 앞 | **22.97%** | 27.30% | 27.29% | 27.59% |

\* `같은 날 추정`은 그날 검색량이 확정된 뒤 그날의 생활이동량을 추정하는 **동시 지표 실험**이다. 미래 예측 결과로 사용하면 안 된다. 이 경우 19~39세 검색 추가로 학습 모델 WAPE가 15.41%→12.75%로 줄었고, 40개 동 중 38개 동에서 오차가 감소했다. 그래도 지난주 같은 요일 값만 쓰는 12.31% 기준선보다 높다.

**현재 결론:** 일별 연령 제한 검색은 같은 날 이동과 관련이 있지만, 이 단순 모델에서 **미래 이동량을 선행 예측하는 데 도움이 된다는 결과는 없다.** 특히 91일 앞에서는 19~39세 검색을 넣은 모델의 오차가 늘었다. 검색 신호가 원래 없는 것인지, 지금의 절대 지수·시차·모델 설계가 부족한 것인지는 이 결과만으로 구분할 수 없다. 학습 모델 자체가 단순 요일 기준선보다 나쁘므로 모델 개선도 필요하다.

## 다음 검증

1. 2024-08~10 생활이동 급증과 2025-03~04 원자료 정밀도 변화를 확인하고, 사전에 정한 정상 구간에서도 평가한다.
2. 월별 프로젝트 목표에 맞게 **정확히 달력상 3개월 앞**을 정의한다. 91일은 근사다.
3. 검색 절대 지수 외에 훈련 기간 기준의 동별 이상치, 검색 증가율, 7일·28일 평균과 더 긴 선행 시차를 별도 검증 기간에서 선택한다.
4. 일별 모델과 7일·월별 집계 모델을 같은 미래 정보 조건으로 비교하고, 이동량 WAPE와 ‘증가할 동’ 순위 성능을 각각 보고한다.
