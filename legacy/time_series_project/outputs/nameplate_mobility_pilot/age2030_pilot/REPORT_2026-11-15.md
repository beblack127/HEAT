# 20·30대 4+5+7 생활이동 예비 실험

2026-11-15 기준. **중간발표용 탐색 결과**이며, 40개 동에서 고른 모델을 같은 시험 구간으로 비교했으므로 일반화 성능으로 해석하지 않는다.

## 타깃과 자료

- [서울시 생활이동 OA-22298](https://data.seoul.go.kr/dataList/OA-22298/F/1/datasetView.do)의 **도착 행정동**, 이동목적 **4+5+7**, 남녀 **20대+30대** 추정 이동인원을 합산하고 해당 월 관측일 수로 나눴다. 단위는 **일평균 추정 이동인원**이다. 같은 사람이 여러 번 이동할 수 있으므로 고유 방문자 수는 아니다. 4+5+7 역시 여가 방문자의 확정값이 아닌 핫플 방문 활동의 대리 지표다.
- 원자료를 2023-01~2025-08의 32개월에 대해 재집계했다. 2023-01~2025-07에는 426개 행정동, 2025-08에는 분동으로 427개가 잡혔다. 기존 40개 동의 **전 연령 4+5+7 집계값과 월별로 일치**했다(최대 절댓값 차이 0).
- 40개 동에서 20·30대 비중은 동·월 비가중 평균 45.6%다. 이는 서울 전체 비중이 아니다.
- 검색량: HEAT가 행정동에 매핑한 네이버 검색 **상대 점유율**. 실제 검색 건수가 아니다. 생활인구: 기존 월별 자료. 지하철: 행정동과 연결된 가장 가까운, 전 기간 자료가 있는 역의 일평균 하차량. 역은 동 경계를 가로질러 이용되므로 **동 방문자 수가 아닌 공간 대리 변수**다.
- 음식점 개폐업 자료는 현재 확인한 HEAT 가공본이 서울시 전체 월별 잠정 합계여서 동별 feature로 투입하지 않았다.

## 평가 설계

40개 예비 동 × 2025-01~08의 8개월 = **320개 동·월**. 모델 계수는 2023-03~2024-11 자료로 적합했고, 각 예측 월 `m`에는 `m−2`까지 관측할 수 있다고 가정해 2개월 앞을 예측했다. 예측이 끝난 뒤 실제로 새로 관측된 한 달을 상태에 추가하되 계수는 다시 적합하지 않았다. 검색·생활인구·역 하차량을 직접 넣는 모델에는 `m−2` 값을 썼다. 네이버 별도 예측 실험은 검색량의 `m−1`, `m` 값을 `m−2`의 마지막 값으로 각각 예측해 ARIMAX에 넣었다. 따라서 미래 실제 검색량을 쓴 결과가 아니다.

WAPE = `Σ|실제−예측| / Σ실제 × 100`. 낮을수록 이동인원 수준 예측의 총 절대오차가 작다.

| 방법 | WAPE |
|---|---:|
| 2개월 전 값 그대로 | 14.73% |
| 전년 같은 달 값 그대로 | 18.63% |
| ARIMA | 13.72% |
| SARIMA | 13.59% |
| ARIMAX + 생활인구 | 14.20% |
| ARIMAX + 네이버 검색 | 16.10% |
| SARIMAX + 네이버 검색 | 16.67% |
| ARIMAX + 생활인구 + 네이버 검색 | 16.70% |
| ARIMAX + **별도 예측한 네이버 검색** | 14.03% |
| ARIMAX + 근처 역 하차량 | 12.00% |
| SARIMAX + 근처 역 하차량 | **11.76%** |

역 하차량을 넣은 SARIMAX가 SARIMA보다 WAPE가 **1.83%p 낮았고**, 40개 동 중 30개 동에서 절대오차가 줄었다. 다만 역을 여러 동이 공유하고, 이 40개 동은 대표 표본이 아니므로 재현 여부를 더 확인해야 한다. SARIMA 계열 120개 적합 중 47개에서 최적화 관련 경고가 기록됐으며, 재시도 후 최종 적합은 수렴했다.

**핫플 발견 성능은 별개다.** 2025-01~07에 전년 동월 대비 실제 증가율 상위 10개 동과 예측 상위 10개 동의 일치 수를 비교하면 SARIMA는 34/70, 역 하차량 SARIMAX는 35/70이다. 역 변수가 이동량 오차를 줄인 결과가 곧바로 ‘앞으로 뜰 동’ 발견 개선으로 이어졌다고 볼 근거는 아직 없다. 2025-08은 2024-08 원자료 급증이 전년 대비 증가율을 왜곡할 수 있어 이 순위 분석에서 제외했다. 이 순위 지표는 WAPE 결과를 본 뒤 추가했으므로 탐색적이다.

## 한계와 다음 실험

1. 2024-08~10에 원자료 급증이 있으며 20·30대 집계에도 남아 있다. 자료 정의·수집 체계의 변화를 확인하고, 해당 구간을 제외한 민감도 실험이 필요하다.
2. 한 번의 2025 시험 구간과 선택된 40개 동만으로 feature 효과를 확정할 수 없다. 사전 고정한 시간 구간에서 서울 전체 동으로 확장하고, 동별·기간별 성능을 함께 보고해야 한다.
3. 검색은 현재 상대 점유율이고 2개월 전 값 또는 단순한 마지막값 예측을 사용했다. 검색 신호의 시차·정규화·계절성을 훈련 구간 안에서 정하고, 별도 검색 예측의 정확도도 평가해야 한다.
4. ‘핫플’은 이동인원 수준만으로 결정하지 않는다. **방문 규모와 성장률의 기준**, 기존에 알려진 사례와 외부 지표로 정의를 검증한 뒤, 후보 동 순위의 정밀도와 거짓 양성을 평가해야 한다.
5. 서울 전체의 단순 기준선은 `lag2` WAPE 13.71%, `lag12` 17.23%(각 3,407 동·월)이다. **동 집합이 달라 위 40개 동의 모델 수치와 직접 비교할 수 없다.** 서울 전체 모델 적합은 아직 실행하지 않았다.
