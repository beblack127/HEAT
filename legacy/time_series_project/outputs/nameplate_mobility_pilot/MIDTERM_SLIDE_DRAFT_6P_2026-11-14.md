## 2. 제안 발표 피드백: 정의와 예측 창 · 50초

### 화면에 넣을 문구

**예측 대상과 기간을 구분했습니다**

```
보조 분석  검색·음식점   2022 시작 → 2024·25 평가 → 2026 시험 보류
           “향후 3개월” = 검색 평균 / 개폐업 합계

주 연구    생활이동       2023 시작 → 한 달의 이동량 예측
           월초에 m−2까지 확인 → 목표 월 m
```

하단 시계열 세 개의 짧은 라벨: **규모가 큰 동 · 꾸준히 느는 동 · 일시 급증 후 복귀**

### 화면 구성

두 개의 가로 시간축을 위아래에 배치. ‘3개월 묶음’과 ‘한 달 목표’를 서로 다른 색으로 강조. 하단 세 개의 시계열 모양은 단순한 선으로 보여 주고 설명문은 달지 않는다.

### 발표자 메모

- 실제로 받은 피드백은 “왜 2022~25년인지, 왜 3개월인지, temporal spike가 무엇인지 정의를 설명하라”는 것이었다.
- 팀원 보조 분석은 검색이 2022년에 시작하므로 그때부터 공통 기간을 잡았다. 2024·2025년을 차례로 평가했고, 2026년 최종 시험은 리포트 시점에 아직 하지 않았다. ‘3개월’은 3개월 뒤 한 달이 아니라 **앞으로 세 달 평균/합계**다. *처음부터* 3개월을 기본으로 고른 이유는 담당자에게 확인해야 한다.
- 주 연구는 공식 생활이동의 2023년 이후 자료를 쓰고, 목표 월 한 달을 예측한다. 두 실험의 성능을 합쳐 말하지 않는다.
- 일시 급증은 계절적 평소 수준보다 크게 올라갔다가 1~3개월 안에 돌아오는 **후향적 유형**이다. 판정 임계값은 학습 구간에서 확정할 예정. 현재 2024년 8~10월은 원인 미확인 ‘급증 후보’이다.
- “슬라이드 문장을 줄여라”는 두 번째 피드백은 덱 전체의 화면 구성으로 반영했다.

## 3. 데이터 파이프라인과 진행 현황 · 55초

### 화면에 넣을 문구

**생활이동이 정답, 다른 자료는 과거 입력입니다**

```
생활이동 y ─────────────────────────┐
검색 · 음식점 · 지하철 · 생활인구 X ──┼─> 행정동×월 ─> 이동량 예측
427동 이름표·공식 동 코드 ───────────┘
```

하단: **427동 연결 완료 | 40동 초기 모형 완료 | 427동 예측·검색 결합 진행 중**

### 화면 구성

큰 가로 흐름도 하나. `y`는 한 색, 보조 `X`는 다른 색. 하단 진행 상태는 짧은 한 줄로만.

### 발표자 메모

- `y`는 서울시 **내국인·도착 행정동·목적 4(쇼핑)+5(관광)+7(기타)** 월별 일평균. `기타`가 넓어서 ‘실제 관광객 수’라고 부르지 않는다.
- 이름표는 검색어·역을 행정동에 붙이는 연결표이지 월별 방문 데이터가 아니다. 신설 동의 과거 값을 임의로 만들지 않는다.
- 지금의 ARIMAX·SARIMAX에 들어간 X는 **낮 생활인구**다. 팀원 검색·음식점 자료는 생활이동 모델에 아직 결합하지 않았다.
- 팀원 검색·개폐업 자체의 예측 리포트는 보조 연구 결과로 소개할 수 있지만, 생활이동의 모형 성능과 구분한다.

## 4. 초기 학습과 평가 방법 · 45초

### 화면에 넣을 문구

**같은 40개 동, 같은 평가 월에서 비교했습니다**

```
2023.03 ───────── 2024.11       2025.01 ─── 2025.08
       모형 적합                       초기 평가
```

`기준선 2개  |  ARIMA · SARIMA  |  ARIMAX · SARIMAX (+생활인구)`

작은 각주: **월초 예측 · 마지막 사용 관측값 m−2 · 총 320 동×월**

### 화면 구성

가로 시간축 하나와 모델군 세 라벨. 학습/평가 기간을 색으로 구분.

### 발표자 메모

- 목표 월의 두 달 전까지 관측한 생활이동으로 2개월 앞을 예측한다. 단순 기준선은 2개월 전 값과 전년 동월 값.
- 네 모델 모두 **같은 생활이동 `y`**를 예측한다. ARIMA/SARIMA는 과거 `y`, ARIMAX/SARIMAX는 과거 `y`와 두 달 전 생활인구를 썼다.
- 차수를 고정한 **초기 백테스트**다. 독립된 validation으로 모델을 고르고 최종 test를 한 결과가 아니다. 2024년 8~10월 급증이 학습에 들어 있어 일반화 주장은 보류한다.

## 5. 초기 결과: 생활인구 추가는 개선하지 못함 · 80초

### 화면에 넣을 문구

**생활인구를 추가해도 WAPE가 낮아지지 않았습니다**

가로 막대에 직접 붙일 값 (낮을수록 좋음):

| 모형 | WAPE |
|---|---:|
| 두 달 전 값 | 11.96% |
| 전년 동월 | 17.20% |
| ARIMA | 10.91% |
| SARIMA | **10.89%** |
| ARIMAX + 생활인구 | 11.54% |
| SARIMAX + 생활인구 | 11.75% |

하단 작은 각주: **40동 · 2025.01–08 · 320 동×월 · 검색 변수 미포함**

### 화면 구성

한 장의 가로 막대그래프. 두 기준선은 회색, ARIMA/SARIMA는 진한 단색, 생활인구 추가 두 모델은 같은 강조색. 2025년 전체 결과를 나란히 놓지 않는다. 숫자는 막대 끝에 쓰고 장문의 해석은 삭제.

### 발표자 메모

“생활이동만 쓴 SARIMA가 10.89%로 가장 낮지만 ARIMA 10.91%와 차이는 작습니다. 생활인구를 추가한 두 모형은 오히려 오차가 커졌습니다. 짧은 동별 이력이나 2024년 급증의 영향을 점검하겠습니다. 이 결과는 검색량의 효과가 없다는 뜻은 아닙니다.”

## 6. 다음 단계와 최종 평가 · 45초

### 화면에 넣을 문구

**검색·음식점이 이동량 예측에 정보를 더하는지 확인하겠습니다**

```
427동 월별 표 완성 → 검색·음식점 과거값 결합 → 동일 동·월 비교
                                   ↓
                       품질 점검 후 2026년 최종 시험
```

작은 각주: **2025년 9월 이후 원천 차이 · 동 경계 변경 · 자료 공개일 확인**

### 화면 구성

간단한 한 방향 흐름과 그 아래 품질 관문 한 줄. 예상 성능 수치를 꾸며 넣지 않는다.

### 발표자 메모

- 계획된 시간순 평가: 2023~24 초기 학습, 2025년 1~8월 변수 선택·검증, 2026년 1~10월 최종 시험 **후보**. 2025년 9월 이후 공식 원천 차이와 2024년 급증을 점검해야 확정할 수 있다.
- 검색·음식점 X를 하나씩 추가하고 **같은 평가 동·월**에서 과거 생활이동만 쓴 모델과 비교한다. 상승 상위 동 적중률도 보조 평가한다.
- 기대 결과는 성능 개선을 보장하는 것이 아니라 “어떤 보조 신호가 도움이 되는지, 도움이 되지 않는지 검증하고 후보 동을 제시”하는 것이다.
