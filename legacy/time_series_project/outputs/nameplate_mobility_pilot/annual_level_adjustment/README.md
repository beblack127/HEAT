# 전년 같은 주 기준선의 최근 수준 보정 실험

20·30대 목적 4+5+7 주간 일평균 생활이동, 네이버 검색지수가 매핑된 동일한 419개 동, 각 원점 이후 13주를 평가했다. 두 방법 모두 예측 원점에서 알 수 있는 이동량만 사용한다.

- `Same week last year`: 예측 주보다 52주 전의 실제 이동량.
- `Yearly + recent level`: 위 값에 `clip(직전 4주 평균 / 전년 대응 4주 평균, 0.5, 1.5)^0.5`를 곱함. 계수 `0.5`는 탐색적 고정값이며 최적화하지 않았다.

| 예측 원점 | 전년 같은 주 WAPE | 최근 수준 보정 WAPE |
|---|---:|---:|
| 2024-10-27 | 12.79% | 13.76% |
| 2025-01-26 | 15.51% | 11.71% |
| 2025-04-27 | 8.52% | 8.94% |

최근 수준 보정은 한 원점에서만 개선했다. 따라서 현재 결과로 보정을 기본 모델로 채택할 수 없다. 2024년 8~10월 생활이동 원자료의 서울 전역 급증 가능성도 2024-10-27 원점 결과의 해석을 어렵게 한다. 여러 예측 원점을 사전에 정해 검증하고, 원자료 품질을 확인해야 한다.

재현 코드는 `../run_annual_level_adjustment.py`, 주별 예측은 `predictions.csv`, 요약 수치는 `metrics.csv`, 네 개 사례 동 수치는 `case_metrics.csv`에 있다. 이 실험은 ARIMA 계열 모델을 새로 적합한 결과가 아니라 **전년 기준선에 적용한 단순 보정**이다.
