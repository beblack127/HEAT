# 행정동별 네이버 검색량을 더한 고정 시점 3개월 예측

## 무엇을 비교했나

생활이동을 **유일한 예측 타깃**으로 유지하고, 동별 네이버 검색지수를 외생변수로 더했다. 예측 원점을 **2025-04-27**에 고정해 그 뒤 13주(04-28~07-27)를 한 번에 예측했다. 예측 도중 새 실제 이동량이나 새 검색량을 넣지 않았다. 모든 비교는 양쪽 자료가 있는 **같은 419개 동, 같은 13주**에서 했다. 완전한 생활이동 이력이 있는 424개 동 중 **5개 동은 네이버 지수가 없어 제외**했다.

- 검색 자료: HEAT의 `행정동_검색지수_월별.csv`, `tier=전체`의 동별 `index`. 네이버 API 검색어 트렌드를 이름표에 매핑한 **상대 검색지수**로 실제 검색 건수가 아니다. 해당 동의 이름·역·권역 검색어 신호를 가중 결합한 값이다. 전 연령 월별 자료이며, 동 간 절대 검색 건수 비교로 해석하지 않는다.
- 정보 시점: 타깃 주 `T`에 대해 `T−13주`가 속한 달보다 **한 달 이전의 완료된 검색 월**을 사용한다. 고정 백테스트에 투입된 검색은 **2024-12~2025-03**뿐이며 모두 2025-04-27에 이미 알 수 있었다. 마지막 수집 시점 2025-08-31에서 만든 2025년 9~11월 예측에는 **2025-05~07** 검색만 사용했다. 자료에 있는 2025년 8월 이후 검색값은 사용하지 않았다.
- 모델: 기존 ARIMA/SARIMA/ARIMAX/SARIMAX와, `검색만` 또는 `검색+13주 전 생활이동`을 외생변수로 준 ARIMAX/SARIMAX. 각 동·모델의 학습 주 범위는 동일하고 외생변수 표준화는 학습 구간에서만 계산했다. 마지막 수집 시점 예측은 실제값이 없어 성능 평가하지 않는다.

## 419개 동의 고정 원점 백테스트

| 모델 | 다음 13주 전체 WAPE | 13주차 WAPE |
|---|---:|---:|
| **전년 같은 주** | **8.52%** | **8.29%** |
| ARIMA | 19.17% | 23.51% |
| SARIMA | 19.45% | 23.01% |
| ARIMAX: 13주 전 생활이동 | 19.34% | 22.54% |
| SARIMAX: 13주 전 생활이동 | 18.93% | 21.87% |
| ARIMAX: **검색** | **16.78%** | 20.94% |
| SARIMAX: **검색** | **16.93%** | 20.35% |
| ARIMAX: **검색+생활이동** | **16.62%** | 19.73% |
| SARIMAX: **검색+생활이동** | **16.28%** | 19.00% |

검색을 넣은 SARIMAX의 13주 전체 WAPE는 18.93→16.93%, 검색과 과거 생활이동을 함께 넣으면 **16.28%**다. 후자는 **419개 중 247개 동**에서 검색 없는 SARIMAX보다 절대오차가 작았다. 하지만 전년 같은 주 기준선보다 나은 동은 **91개**뿐이다. 따라서 “동별 검색이 수업 모델의 오차를 일부 줄였다”는 탐색적 결과는 있지만 **검색을 넣어 예측에 성공했다는 결론은 아니다**. 이 원점 하나를 보고 구성한 모델을 일반화하거나 2025년 평가 구간을 완전히 독립적인 최종 시험이라 부르면 안 된다.

## 이전에 일별 재수집한 40개 동도 별도 확인

20·30대 생활이동과 연령대가 가까운 **네이버 19~39세 일별 검색지수**를 완전한 주로 묶어, 타깃보다 13주 전 같은 주의 검색을 입력했다. 같은 40개 동·13주에서 전년 같은 주 WAPE는 **6.61%**, 검색 없는 ARIMA **21.43%**, 일별 검색 ARIMAX **21.05%**, 일별 검색 SARIMAX **22.23%**였다. 월별 전 연령 HEAT 검색을 쓴 ARIMAX는 이 40개 동에서 **18.01%**였다. 두 검색 자료는 연령·키워드 묶음·정규화가 달라 직접적인 일별 대 월별 효과 비교가 아니다. **일별 검색이 더 도움이 된다는 증거는 현재 없다.**

## 해석과 한계

검색 지표는 2022년 기준 검색어 묶음으로 정규화됐고, 여기서는 미래 월을 읽지 않았다. 다만 이름표 연결은 후향적으로 만든 2025년 경계·검색어 목록을 사용하므로 **완전히 당시 구축된 실시간 시스템의 재현은 아니다**. 네이버 검색은 전국 검색이며 지명 중복·키워드 선택의 오차도 있다. 동별 검색이 실제 방문보다 앞서는지, 단지 계절 패턴을 대변하는지는 이 한 원점으로 가르지 못한다. 특히 강한 전년 기준선과 결합해도 개선되는지 별도로 검증해야 한다.
