# 2026년 주간 생활이동 ML 예측 실험 계획

## 대상과 예측
- 기존 HEAT 정답: 도착 행정동의 20~39세, 목적 4+5+7 이동을 일별 합산하고 월요일~일요일 유효 일별 값의 평균으로 집계한다. 유효일 4일 미만은 결측이며 기존 동 통합 규칙을 따른다.
- 2023년부터 2025-12-28까지 학습해 2025-12-29~2026-03-29의 13주를 한 번에 예측한다. 목표 주 종료일은 2026-01-04~03-29다. 2026년 관측으로 갱신하거나 재학습하지 않는다.

## 모델과 입력
- Ridge와 LightGBM은 각각 모든 동과 예측 거리를 함께 학습한다. 학습 행은 행정동 × 예측 기준 주 × 예측 거리 h(1~13)로 구성하고, h를 입력해 해당 주의 이동량을 직접 예측한다. 보정된 주간 이동량에 `log1p`를 적용하고 예측은 `expm1`로 복원한 뒤 음수를 0으로 제한한다. 동 ID, origin 기준 자기 시차 1·2·3·4·13·52주, 직전 4·13주 평균, 목표 주의 52주 전 값, 연간 365.25/7주 주기의 Fourier sin/cos K=3쌍을 사용한다. 과거 입력은 해당 origin까지의 관측만 쓴다.
- Ridge alpha ∈ {0.1, 1, 10, 100, 1000}; LightGBM num_leaves ∈ {7, 15, 31}, min_data_in_leaf ∈ {50, 200}, learning_rate ∈ {0.03, 0.07}, 최대 2,000회, 조기 종료 patience 100을 사용한다. 결측 처리·표준화·동 ID 인코딩은 각 학습 분할에서만 적합한다.
- 기본 입력만, 검색 비중만, F&B 순개업률만, 지하철 하차만, 세 변수 모두를 기본 입력에 추가한 다섯 조건을 비교한다. 기존 시차: 목표 주 기준 검색과 F&B는 4개월 전, 지하철 하차 4주 평균은 13주 전. F&B는 일괄 폐업을 제외한 최근 3개월 (개업−폐업) 합 / 3개월 전 영업 점포 수다. 자료의 관측·공개 시점이 origin 이후면 사용하지 않고 미래 관측으로 결측을 채우지 않는다.
- 각 조건의 단독 예측과 보정된 52주 전 같은 주 예측을 50:50으로 결합한 예측을 비교한다. 결합은 역변환 후 원 단위에서 수행한다.

## 보정, 튜닝 및 평가
- 기존 이상 보정을 학습값·자기 시차·전년 값에 적용한다. 2024-08~10 서울 합계의 관측/기대 배율로 각 동을 나누며, 기대값은 전년 같은 주 서울 합계 × 2024년 1~7월/2023년 1~7월 비율이다. 각 cutoff에서 이미 관측된 구간만으로 배율을 산출하고 미래 구간은 쓰지 않는다. 검증 정답은 보정하지 않은 원자료다.
- 외부 검증 origin은 기존 2024-10-27, 2025-01-26, 2025-04-27, 2025-07-27이다. 각 origin의 과거에 한정한 확장창 내부 시간 검증으로 하이퍼파라미터와 조기 종료 반복 수를 선택한다. 내부 학습 라벨은 내부 cutoff까지, 내부 검증 라벨은 외부 cutoff까지 모두 알려진 것만 사용한다. 전처리·보정·특성 계산을 각 분할에서 다시 수행하고 내부 검증 원자료 WAPE로 선택한다. 선택 후 외부 cutoff까지 재적합해 다음 13주를 평가한다.
- 기존 공통 416개 동의 동일한 유효 정답 행에서 origin별 WAPE = 100 × Σ|실제−예측| / Σ|실제|를 계산한다. 네 origin WAPE의 산술평균과 이상 구간 영향이 없는 2025-01-26·2025-04-27의 두 origin 평균을 보고한다. 조건별 결측·제외 행과 동별 차이도 기록하고 동일 행 비교가 불가능하면 명시한다.
- 기존 4시점 평균 참고치: 보정 전년 같은 주 + 보정 ARIMA·Fourier 결합 11.76%, 보정 전년 같은 주 + 보정 ARIMA 결합 11.68%. 기존 2시점 평균은 각각 9.96%, 10.70%다. 기존 수치는 회고적 보정 결과이므로 cutoff별 보정 재산출 결과와 차이가 날 수 있다.
- 외부 평가를 비교해 모델·입력·결합 방식을 정한 다음 2025-12-28 cutoff 이전의 내부 시간 검증으로 설정을 다시 고르고 허용된 전체 학습 자료에 재적합해 최종 13주를 한 번 예측한다. 2026년 실제값은 선택·전처리·보정에 사용하지 않는다. 2026년 평가는 예측과 선택을 고정한 후 원자료 정답이 확보되면 별도로 수행한다.
